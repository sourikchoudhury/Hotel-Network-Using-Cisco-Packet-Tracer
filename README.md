# Hotel Network Simulation Using Cisco Packet Tracer

A simulated hotel network designed and implemented using **Cisco Packet Tracer** as a college networking project. The project demonstrates the design, configuration, and testing of a basic network infrastructure for a hotel environment.

## Overview

The objective of this project was to design a functional computer network for a hotel using Cisco networking devices and simulate communication between different departments and network segments.

The network was configured and tested in Cisco Packet Tracer to verify connectivity and basic network functionality.

## Network Architecture

The simulated hotel network consists of multiple network devices and end-user systems representing different areas/departments of a hotel.

The network topology includes:

- Routers
- Switches
- PCs
- Servers
- End devices
- Interconnected network segments
